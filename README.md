# Fit With Nehal — Winter Arc 2026

A 92-day personal Winter Arc tracker for 1 October 2026 through 31 December 2026.

## Included
- Workout
- Hydration
- Sleep
- Daily study targets
- Coding: minimum 30 minutes
- Spoken English: minimum 39 minutes
- No social media
- No unnecessary time waste
- Daily percentage
- 92-day calendar
- Current and best streak
- Browser localStorage persistence

## Deploy on Netlify
1. Extract this ZIP.
2. Go to Netlify and choose Add new project / Deploy manually.
3. Upload the extracted folder.
4. The site will be live.
